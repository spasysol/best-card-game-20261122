Cinderfall is a duel card game: outwit the Ash Warden across four elements — Ember, Tide, Gale and Stone — in a race to bring its life to zero. Each round you draw to five cards, spend energy on creatures and spells, and clash slot by slot, where elemental advantage deals +2 and two creatures of one element resonate for +1 power each. The Warden announces what it gathers every round, so its plan can be read and countered. Static files, no network, no build step — open game/index.html and play.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
